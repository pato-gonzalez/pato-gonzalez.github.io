Hermes privacy policy

Hermes is a private, single-user application used only by its owner with the owner's own Google accounts.

  • Google user data (Gmail, Calendar, Sheets) is accessed only to perform tasks the owner requests.
  • Data is processed on the owner's own server and is not sold, shared with third parties, or used for advertising.
  • Gmail access is read-only.
  • Access can be revoked at any time at myaccount.google.com/permissions.

Hermes's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
